# OldDropItems

Плагин который контролирует дроп предметов при смерти игрока. Вместо разлёта дропа в разные стороны можно сделать чтобы они падали в одну кучу, подлетают вверх и не подбираются первые несколько тиков. Так-же плагин поддерживает 1.21-26.3 версии.

## Что делает

- **Разброс** - предметы падают не в одну точку, а по кругу.
- **Подброс** - предметы подлетают вверх.
- **Задержка подбора** - нельзя подобрать предметы первые N тиков после смерти.
- **Выключатель** - можно отключить плагин через конфиг, не удаляя его.

Всё остальное ванильное: предметы исчезают через 5 минут, не дропаются при `keepInventory: true`, не появляются в пустом инвентаре.
И Никаких зависимостей, кроме Paper 1.21+.

## Конфиг

Файл `plugins/OldDropItems/config.yml` появится после первого запуска.

```yaml
# Включен ли плагин
enabled: true

# Горизонтальный разброс предметов
# 0.0 - предметы падают ровно на месте смерти
# 1.0 - максимальный разброс в сторону
# Итоговая горизонтальная скорость = значение * 0.5
scatter: 0.3

# Высота подбрасывания предметов вверх
# 0.0 - без подбрасывания
# 2.0 - максимальный подброс вверх
# Итоговая вертикальная скорость = значение * 0.4
throw-height: 0.5

# Задержка перед возможностью подбора предметов (в тиках, 20 тиков = 1 секунда)
# 0 - подбирать можно сразу
pickup-delay: 5
```

Если удалить строку - подставится значение по умолчанию. Если поставить `scatter: 0` и `throw-height: 0`, предметы будут падать в точку смерти.

## Команда

```
/olddrop reload
```

Перечитывает конфиг без перезапуска. Требует право `olddrop.reload` (по умолчанию только у операторов).

## Важно про приоритет (прочитать всем!)

Плагин слушает `PlayerDeathEvent` на `HIGHEST` и очищает список дропа перед ручным спавном. Если у вас стоит другой плагин на смерть, тогда он должен быть на LOW/NORMAL/HIGH. Два плагина на `HIGHEST` возможно дадут большое количество ошибок и, возможно, дюп предметов. Это единственный реальный конфликт.
