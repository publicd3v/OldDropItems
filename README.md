# OldDropItems

Плагин который контролирует дроп предметов при смерти игрока. Вместо разлёта дропа в разные стороны можно сделать чтобы они падали в одну кучу, подлетают вверх и есть задержка подбора.

## Требования

- Paper 1.20-26.3
- Java 21+

## Команды

| Команда | Право | Описание |
|---|---|---|
| `/olddrop reload` | `olddrop.reload` | Перезагружает конфигурацию|

## Конфигурация

```yaml
# Включен ли плагин
enabled: true

# Горизонтальный разброс предметов
# 0.0 - предметы падают ровно на месте смерти
# 1.0 - максимальный разброс в сторону
# Итоговая горизонтальная скорость = значение * 0.5
scatter: 0.3

# Высота подбрасывания предметов вверх
# 0.0 - без подбрасывания
# 2.0 - максимальный подброс вверх
# Итоговая вертикальная скорость = значение * 0.4
throw-height: 0.5

# Задержка перед возможностью подбора предметов (в тиках, 20 тиков = 1 секунда)
# 0 - подбирать можно сразу
pickup-delay: 5
```
Все значения автоматически ограничиваются безопасными диапазонами, даже если в конфиге указаны некорректные числа.

## Совместимость

- Плагин объявлен как `api-version: '1.20'`, поэтому загружается на Paper 1.20 и новее.
- Поддерживается Folia (`folia-supported: true`).
- Используется только Paper API, без NMS.

## Важно про приоритет (прочитать всем!)

Плагин слушает `PlayerDeathEvent` на `HIGHEST` и очищает список дропа перед ручным спавном. Если у вас стоит другой плагин на смерть, тогда он должен быть на `LOW/NORMAL/HIGH`. Два плагина на `HIGHEST` возможно дадут большое количество ошибок и, возможно, дюп предметов. Это единственный реальный конфликт.
